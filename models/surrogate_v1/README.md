# surrogate_v1: 냉각 채널 스칼라 대리모델 (책 05-5, 6장)

| 항목 | 내용 |
|---|---|
| 모델 | MLP (SiLU, 은닉층 64개 x 3층), 20000 에포크, CPU 학습 |
| 입력 | H [mm], e_ratio (e/H), N (리브 개수), U [m/s] |
| 출력 | dp [m2/s2] (압력손실, x=5mm 단면 평균 운동학적 압력), dT_max [K], dT_avg [K] |
| 고정 조건 | 열유속 10 kW/m2, 입구 온도 20 °C, 물, 2D 층류 정상 해석 (3장) |
| 학습 데이터 | data/cooling_v1 train 418개 (SHA-256은 mlp.json) |
| 파일 | mlp.pt (가중치), mlp.json (구조·표준화·입력 범위·지문) |

## 사용 가능 범위

mlp.json의 `input_range`가 학습 범위입니다. 이 범위 밖 입력은 경고 없이도 숫자를
내놓으므로, 호출하는 쪽에서 먼저 검사해야 합니다(06-3).

| 입력 | 범위 |
|---|---|
| H | 1.5 ~ 2.5 mm |
| e/H | 0.2 ~ 0.4 |
| N | 4 ~ 15 (정수) |
| U | 0.05 ~ 0.15 m/s |

## 성능 (6장 실측)

| 데이터 | 평균 상대 오차 dp / dT_max / dT_avg | 최대 상대 오차 |
|---|---|---|
| test (범위 안, 90개) | 0.084% / 0.065% / 0.038% | 0.83% |
| ood_U (U 0.15~0.20) | 0.58% / 0.25% / 0.24% | 3.2% |
| ood_H (H 2.5~3.0) | 0.41% / 0.31% / 0.17% | 1.7% |

- 기본 격자(높이 30칸)의 격자 오차는 압력손실 약 1.1%, 최고 온도 약 1.5%,
  평균 온도 약 0.23%입니다(03-5). 대리모델 오차는 이 CFD를 흉내 낸 오차입니다.
- 오차가 상대적으로 큰 곳: 리브 4~5개, e/H 0.35 이상이면서 U 0.12 이상인 모서리,
  각 입력 범위의 양 끝(06-5).
- 범위 안이라도 e/H와 U가 모두 큰 모서리는 CFD 정상해가 수렴하지 않는 조합이
  있습니다(04-4). 이 영역의 예측은 CFD로 다시 확인합니다.
